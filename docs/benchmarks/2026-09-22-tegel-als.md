## 3. Reading the numbers

- Tree count vs CHM baseline: the CHM local-maxima count (1 m cells, 3 m window, 3 m
  minimum height, from the ALS classes only) is a crude reference that over-counts broad
  crowns and under-counts suppressed trees; agreement within +-50 % is what we ask of a
  first pass.
- Height distribution: model heights are `top_z` minus the 1 m ground grid at the stem;
  compare the median with the CHM maxima median.
- Ground vs vegetation: the 2x2 table compares model `semantic == 0` with ALS class 2. A
  low agreement here means the semantic head, not only the instance head, fails on ALS.
- <observations: fragmented crowns, merged neighbours, trees cut at cylinder borders,
  ground points inside instances>

## 4. Recommendation on ALS fine-tuning

Decision rule (implemented in `ff3d_geo.report.recommend`): the checkpoint is usable as a
first pass on ALS if, per tile, the model tree count is within 50 % of the CHM baseline
count and the median model height is within 3 m of the median CHM maxima height. If either
tile fails either criterion, fine-tuning on ALS is recommended.
